# 🦁 초원의 제왕 사자: 야생 사냥 어드벤처 (Lion Safari Hunt)

초원을 질주하며 다양한 동물들을 사냥하는 10단계 스릴 만점 웹 액션 게임입니다!  
동물들의 거리에 따른 **귀여운 표정 변화**와 **1분 제한시간 굶주림 주저앉음 시스템**이 구현되어 있습니다.

---

## 🎮 게임 특징 및 시스템

### 1. 🏁 총 10단계 스테이지 & 점진적 속도 증가
단계가 올라갈수록 동물들의 도망 속도와 회피 기동이 빨라집니다!
- **1단계**: 🐰 **아기 토끼** - 호기심 많고 깡충깡충 여유만만
- **2단계**: 🐇 **산토끼** - 날쌘 발놀림의 갈색 산토끼
- **3단계**: 🦌 **아기 가젤** - 경쾌하게 뛰어다니는 어린 영양
- **4단계**: 🦌💨 **톰슨 가젤** - 지그재그 회피 기동의 달인
- **5단계**: 🦓 **얼룩말 망아지** - 앙증맞은 줄무늬 망아지 무리
- **6단계**: 🦓⚡ **야생 얼룩말** - 성체 얼룩말의 빠른 질주
- **7단계**: 🐗 **품바 혹멧돼지** - 흙먼지를 일으키며 달리는 혹멧돼지
- **8단계**: 🦤 **사바나 타조** - 긴 두 다리로 성큼성큼 초원의 스프린터
- **9단계**: 🐂 **야생 물소/누우** - 묵직한 파워와 엄청난 돌진 속도
- **10단계**: 👑✨ **전설의 황금 가젤** - 최고 난이도의 궁극의 스피드!

### 2. 🍖 사냥 목표 & ⏱️ 1분(60초) 제한 시간 시스템
- **단계당 목표**: 동물 **3마리** 사냥
- **제한 시간**: 각 단계마다 **1분 (60초)** 제공
- **굶주림 주저앉음 (Starve Collapse)**:
  - 1분 안에 3마리를 모두 잡지 못하면 사자가 기운이 빠져 털썩 바닥에 주저앉습니다.
  - 배에서 꼬르륵 소리가 나며 눈물을 흘리는 슬픈 연출과 함께 **[🔄 이 단계 다시 도전하기]** 또는 **[🚪 끝내기 / 처음부터]**를 선택할 수 있습니다.

### 3. 🥰 동물들의 표정 변화 시스템 (실시간 감정 레이더 탑재)
사자와의 거리에 따라 동물들의 표정과 말풍선이 실시간으로 변화합니다:
- **여유/장난 (250m 이상)**: 눈웃음(`^w^`), 풀 뜯기(`🌿`), 메롱 놀리기(`:P`)
- **경계/의심 (140m ~ 250m)**: 깜짝 눈(`O_O`), 귀 쫑긋, 식은땀 삐질(`💧`)
- **패닉/공포 (140m 이하)**: 경악 눈과 비명 입(`😱`), 식은땀 펑펑(`💦`), 전속력 질주!
- **잡힐 때**: 빙글빙글 도는 눈(`@_@`), 별 이펙트(`⭐`)
- 우측 상단 **[🔍 근접 동물 표정 돋보기]** 카드를 통해 가장 가까운 동물의 심리 상태와 표정을 실시간으로 감상할 수 있습니다.

### 4. 🕹️ 조작 방법
- **PC**:
  - 이동: `방향키 (↑ ↓ ← →)` 또는 `W, A, S, D` 키, 혹은 `마우스 드래그`
  - 포효 대시: `스페이스바 (Space)` 또는 화면 우측 하단 `[🦁💨 포효 대시!]` 버튼
- **스마트폰 / 모바일**:
  - 화면 터치 시 나타나는 **가상 조이스틱**으로 360도 이동
  - 화면 우측 하단 **[🦁💨 포효 대시!]** 터치 버튼

## 🚀 깃허브(GitHub) 올리기 & Vercel 배포 가이드

이 프로젝트는 순수 웹 표준(HTML5 + Canvas + Vanilla JS + Web Audio API)으로 제작되어 별도의 빌드 과정(npm build 등) 없이 **즉시 배포** 가능합니다.

### 1단계: 깃허브(GitHub)에 업로드하기
1. [GitHub](https://github.com/)에 로그인 후 **New Repository**를 생성합니다. (예: `lion-safari-game`)
2. 터미널(PowerShell 또는 Git Bash)을 열고 이 폴더로 이동합니다:
   ```bash
   cd "C:\Users\예성원\Desktop\game503"
   ```
3. Git 저장소를 초기화하고 파일을 커밋합니다:
   ```bash
   git init
   git add .
   git commit -m "feat: 초원의 제왕 사자 사냥 게임 완성 (10단계, 60초 타이머, 굶주림 시스템, 표정 연출)"
   git branch -M main
   ```
4. 본인의 깃허브 레포지토리 주소를 연결하고 푸시합니다:
   ```bash
   git remote add origin https://github.com/당신의깃허브아이디/lion-safari-game.git
   git push -u origin main
   ```

### 2단계: Vercel(버셀)에 게시하기
1. [Vercel](https://vercel.com/)에 접속하여 GitHub 계정으로 로그인합니다.
2. 대시보드 우측 상단의 **[Add New...]** ➡️ **[Project]** 클릭합니다.
3. 방금 올린 `lion-safari-game` 레포지토리를 찾아 **[Import]**를 누릅니다.
4. Framework Preset은 `Other` 그대로 두고 아무런 설정 변경 없이 **[Deploy]** 버튼을 누릅니다.
5. **10초 안에 멋진 나만의 웹 게임 링크(`https://lion-safari-game.vercel.app`)가 생성되어 전 세계에 공개됩니다!** 🎉
